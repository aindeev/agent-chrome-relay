Set up Chrome Relay on this Mac, so you and my other AI agents can use my signed-in Chrome from the command line, in background tabs.

Repo: https://github.com/aindeev/agent-chrome-relay (read its README first).

1. Check the basics: macOS, Google Chrome, git and Go 1.25+. If agent-browser is missing, install it with `npm i -g agent-browser`. Also check whether Xcode's command line tools are installed (`xcode-select -p`): they're optional, and only needed for signing in with 1Password and for Chrome Relay's own passkeys. If they're missing, tell me that and ask whether I want them. Ask me before installing anything else.
2. Clone the repo to ~/agent-chrome-relay (if it's already there, `git pull` instead). In the clone, run `./build`: it compiles Chrome Relay and signs it on this Mac (with my code-signing identity if I have one, otherwise ad-hoc). If it lists several identities, show me the list and ask which one to use, then run `./build --identity "<that name>"`. Tell me what its last lines say it built. Then run `./chrome-relay setup` and read its output.
3. Installing the extension is my job, not yours. Walk me through it: in each Chrome profile I want agents to use, open https://chromewebstore.google.com/detail/WEBSTORE_ID , click Add to Chrome, then pin it (the puzzle-piece icon in the toolbar, then the pin next to Chrome Relay). Wait until I say it's done.
4. Run `chrome-relay notify test`: macOS asks me to allow notifications from Chrome Relay, which is how I hear that an agent needs me (a sign-in, a passkey to approve). Tell me to allow them, and to let Chrome Relay through any Focus / Do Not Disturb I use. Then run `chrome-relay doctor` and fix whatever it reports until every line is ok.
5. Run `chrome-relay identities`, show me the profiles it found, and ask which email to use by default and which (if any) only for admin work.
6. Smoke test with the default profile:
   agent-browser --cdp "$(chrome-relay url <email>)" open https://github.com
   agent-browser get title
   agent-browser close
   Then confirm with me that nothing moved on my screen.
7. Make sure all my agents know how to use it. Claude Code already has it: setup linked the chrome-relay skill. For Codex, Cursor or other agents, propose a one-line addition to their global instructions (for example ~/.codex/AGENTS.md) that points to <clone>/skill/SKILL.md for any browser step that needs my logins. Show me the edit before you save it.
8. Signing in with 1Password is optional and off by default. Ask me whether I want my agents to sign in to some sites with logins from my 1Password (passwords, 2-step codes, passkeys). If not, skip this. If so, it needs the build with Xcode's command line tools and the 1Password CLI (`brew install 1password-cli`, with 1Password's Settings > Developer > "Integrate with 1Password CLI" on); point me to the README's "Signing in with 1Password" section. Running `chrome-relay vault setup` is my job: it asks me which 1Password accounts, creates a shared vault and a service account in each, and 1Password asks me to approve. Afterwards remind me to move the logins agents may use into those vaults, then run `chrome-relay vault` and show me what agents can see.
9. Approving from my iPhone is optional too. Ask me whether I want to approve agents' sign-ins with Face ID on my iPhone when I'm away from the Mac. If so, point me to the README's "Approving from your iPhone" section: the iPhone app is built from the repo's ios/ folder with Xcode (`./ios/build`, iPhone plugged in), and `chrome-relay phone pair` shows a QR code I scan. Don't run those yourself unless I ask.
10. `chrome-relay do` lets agents carry out a whole goal in one command; for steps that need a decision it uses Claude Haiku through my Claude Code if that's installed. Run `chrome-relay decider` and tell me what it says. It can be faster (~0.15 s a step) with TypeSafe's Jev, which needs a TypeSafe API key and sends the page text of agent tabs to TypeSafe: ask me whether I want that. Saving the key is my job (`pbpaste | chrome-relay decider jev`); never ask me to paste it to you.

Rules while you do this:
- Never print, log or paste the URL from `chrome-relay url`. It contains this Mac's secret.
- Never type my passwords, never pick Google accounts and never complete a sign-in for me. If a page needs a login, stop and ask me. Never ask me for a 1Password token or secret: I type those myself.
- Never drive my Chrome any other way: no --auto-connect, no --cdp 9222, no --headed, no Playwright attached to it and no AppleScript.
